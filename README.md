# Asistente Técnico para Diagnóstico de Consolas y PC — Gate 1

Miniaplicación en Python para el triaje, clasificación de fallas y asistencia diagnóstica en taller técnico. Consume la API de Google Gemini procesando salidas estructuradas en formato JSON y cuenta con manejo explícito de errores y desacoplamiento funcional.

Este proyecto corresponde a la entrega de la **Unidad U1.6: Gate 1 - Habilitación técnica** de la *Especialización en Desarrollo con IA Generativa (Accenture / Skillnest)*.

---

## 🛠️ Requisitos Previos

- **Python:** Versión 3.10 o superior.
- **Git:** Instalado y configurado en la terminal.
- **API Key:** Llave de acceso válida de Google AI Studio (Gemini API).
